# Sensor-Based Hydroponic Systems: Paper Review and Presentation

This project presents a detailed review of recent research on sensor-based hydroponic systems, with a focus on architectures like SmartGrow. The goal is to understand how different environmental parameters are monitored and controlled in modern automated hydroponic setups.

## Overview

- Analyzed key papers on sensor-driven smart agriculture systems
- Focused on the integration of pH, temperature, and nutrient sensors
- Explored real-world systems such as SmartGrow and their sensing architectures
- Presented insights on automation strategies, sensor calibration, and energy-efficient data collection

## Reviewed Topics

- SmartGrow architecture and calibration strategies
- Sensor placement and wireless data transmission
- Nutrient solution management using feedback systems
- Sustainability and scalability of hydroponic automation
